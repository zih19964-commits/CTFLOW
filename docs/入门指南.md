# 入门指南

在项目根目录运行 `.\.venv\Scripts\ctflow.exe`（或 `./start.ps1`）打开 FLUX 工作台。首次进入展示双栏选择页（Hub），可按 `1`、`2`、`3` 在工作流、Worker 角色库与历史运行记录间切换，按 `Enter` 或双击打开所选条目。在工作台或单聊页面，保持底部输入框为空并按左方向键 `←` 即可返回选择页。

### 配置连接与外置扩展

输入 `/worker new` 新建角色，或输入 `/worker <id>` 编辑已有角色（`/worker architect` 用于配置内置编排助手的模型连接）。`base_url` 填写标准 OpenAI Chat Completions 兼容接口根地址（如阿里云百炼兼容地址或 DeepSeek 官方接口地址），API Key 自动保存在操作系统原生凭据管理器（`keyring`）中。点击「刷新模型」可使用当前表单草稿拉取上游可用模型并选择，按 `Ctrl+S` 保存。

外部工具与技能统一存放在 `extensions/` 目录中。`extensions/mcp.json` 直接使用标准 `mcpServers` 格式登记服务，例如联网搜索插件 `deepseek-search-fetch-mcp`：

```json
{
  "mcpServers": {
    "deepseek_web": {
      "command": "uvx",
      "args": ["deepseek-search-fetch-mcp"],
      "env": {
        "DEEPSEEK_API_KEY": "sk-你的密钥"
      }
    }
  }
}
```

可复用技能文件放置在 `extensions/skills/<名称>/SKILL.md` 中。重新打开 Worker 配置窗口即可在 MCP 与 `@技能` 多选列表中用空格键勾选挂载。运行 `ctflow mcp <worker-id>` 可在命令行直接验证并列出该角色可见的全部工具。

### 自然语言建图、可视化编排与回滚

进入 `/chat architect` 向内置编排助手描述业务目标，助手会结合当前已有角色清单输出符合规范的 `mermaid` 拓扑图或通过受限文件系统工具直接创建配置。在单聊中输入 `/flow apply 工作流名称` 可一键提取最后一轮回复中的拓扑图并切换至工作台。所有自动修改均会在 `config/backups/` 生成隔离快照，需要回退时执行 `/rollback`（或命令行 `ctflow rollback`）即可还原至修改前状态。

在工作台中，点击拓扑画布上的任意节点卡片（或双击右侧节点列表）可打开节点装配窗，切换绑定 Worker、补充节点任务或勾选直接上游依赖；输入 `/flow edit` 可在可视化列表与 Mermaid 源码间切换编辑，拓扑回环或悬空引用会在界面实时标红拦截。

### 运行观测与跨目录单行调用

在工作台底部输入普通文本回车可更新当前工作流总任务，输入 `/run` 启动并发调度，输入 `/run stop` 终止在途请求。运行期间点击任意节点即可实时查看流式 Markdown 输出、MCP 工具调用参数、耗时与 Token 统计；完成后输入 `/copy` 复制终点结论，或输入 `/export` 导出完整 Markdown 报告。

在电脑任意目录下均可直接通过单行命令调用已保存的工作流或单个角色：

```powershell
E:\CTflow\.venv\Scripts\ctflow.exe @review "评估当前架构设计方案"
E:\CTflow\.venv\Scripts\ctflow.exe @@judge "给出独立复核意见"
E:\CTflow\.venv\Scripts\ctflow.exe doctor --worker judge --live
```
