## 已实现

点击图中节点或右侧节点列表可装配 Worker，并修改节点名称、补充任务和直接依赖。`/worker` 打开配置入口，支持选择模型或输入任意可用模型 ID、固定上下文及多选技能。技能通过复制到 `skill/<name>/SKILL.md` 加入，打开配置时重新发现。

`/models` 读取服务商模型列表。`/flow` 加载已保存的工作流，`/flow new` 新建，`/flow edit` 编辑，`/flow save 名称` 另存一套。编辑保存后可切换并在重启后加载。配置窗口以 `Ctrl+S` 保存，`Esc` 或右上角 `×` 取消未保存修改。

每个节点通过 SingleRequestRuntime 请求一次模型，使用 OpenAI Python SDK 的异步流式接口。运行会保存 Workflow、Worker 和技能正文快照；节点接收直接上游结果，失败阻断下游，停止取消请求。输出、用量和运行状态保存到 SQLite；`/export` 导出 Markdown。
