# 实现范围

更新日期：2026-11-18。

本文件是当前交付的产品口径。`数据结构课程设计-产品文档.md` 描述完整产品愿景；其中的 P0 项并非全部进入本次最小实现。README、入门指南、实现说明与本文件以当前代码为准。

## 已实现

| 能力 | 当前实现 |
| --- | --- |
| Worker | 独立 `base_url`、API Key、模型、`extra_body`、固定上下文、技能、MCP 服务器引用 |
| Node / Workflow | 直接依赖 DAG，顺序、并行、汇合、失败阻断、停止 |
| 执行 | `asyncio.Semaphore` 限流；每个节点独立客户端；运行快照隔离 |
| 模型协议 | 每个 Worker 可选 Chat Completions、OpenAI Responses 或 Anthropic Messages；流式输出与 usage |
| MCP | `stdio`（真实链路已验证）/ `http`（SDK 支持）服务器；工具发现、调用、结果回填；`max_tool_rounds` 限制 |
| 凭据 | API Key 使用平台加密写入 SQLite（Windows DPAPI，其他平台 Fernet）；旧明文自动迁移 |
| 界面 | FLUX 终端界面、图点击装配、Worker/节点/工作流编辑、模型刷新、运行与导出 |
| 命令行 | `init`、`run`、`worker`、`list`、`show`、`models`、`mcp`、`doctor` |
| 持久化 | `workers`、`workflows`、`runs` 三张表；JSON/Mermaid/Markdown 导出 |

## 部分实现

| 能力 | 差距 |
| --- | --- |
| 实时可视化 | 显示节点状态、当前输出和总 Token；节点卡片未显示模型名、费用明细和工具耗时 |
| MCP 展示 | 节点日志记录工具开始、完成与失败；终端没有独立的工具参数/结果面板 |
| 运行历史 | CLI 可列出和查看；TUI 不提供历史运行回放 |
| 工作流编辑 | 通过表单与 Mermaid 源文本编辑；没有拖拽画布和端口连线 |
| 成本统计 | 支持按模型单价估算；缺少价格时显示未知，节点卡片不展示费用 |

## 验收边界

当前自动化验收覆盖依赖解析、并行汇合、停止、失败阻断、上下文隔离、用量汇总、持久化、DPAPI/Fernet 迁移、MCP stdio 工具、三种协议请求格式和 Textual 主要交互。真实服务验收覆盖 DeepSeek V4.1 Chat Completions 与 MCP `echo` 工具链路；产品文档中的暂停、重试、画布拖拽和历史回放没有对应实现，因此不列入本次验收。
