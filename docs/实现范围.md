# 实现范围

更新日期：2026-11-19。

本文档记录当前代码库已交付的能力边界与后续演进方向。完整产品愿景见 `数据结构课程设计-产品文档.md`，关键架构决策依据见 `docs/adr/`。

### 已交付能力

| 模块 | 当前交付能力 |
| --- | --- |
| Worker 装配 | 独立 OpenAI 兼容 `base_url`、系统 `keyring` 托管 API Key、模型刷新与切换、`extra_body`、固定提示词、外置 `SKILL.md` 与标准 MCP 多选勾选 |
| 内置编排助手 | 独立物理隔离的 `@architect`（源码锁定规范与受管目录窄白名单），支持 `filesystem` MCP 直写配置、`/flow apply` 提取 Mermaid 建图及写前自动快照 `/rollback` |
| DAG 与上下文传导 | Kahn 拓扑分层与精确有向环定位；`asyncio.Semaphore` 并发控制；闭合 XML 标签（`<workflow_input>` / `<upstream>`）携带节点名称与 `@worker_id` 传导直接上游结论 |
| MCP 与多步工具循环 | 外置 `extensions/mcp.json` 兼容标准 `mcpServers`（`stdio` / `http`），预置 `deepseek-search-fetch-mcp` 联网检索模板；同轮 `asyncio.gather` 并行调用工具与 `max_tool_rounds` 三级配额渐进收敛 |
| 纯文件持久化 | `data/workers/`、`data/workflows/`、`data/runs/` 纯文件 JSON 存储，坏文件读取自动跳过隔离；单 Worker 对话保持内存态运行 |
| 终端界面 | 双栏 3D 动态徽标 Hub 选择页（含历史 Run 回放）、圆角字符 DAG 画布、可视化与 Mermaid 双模式工作流编辑器、实时工具步骤轨迹与复制导出 |
| 跨目录命令行与外部调用 | 自动定位安装根目录配置，支持 `ctflow @<workflow> "任务"` 与 `ctflow @@<worker> "问题"` 单行调用（`stdout` 输出结论、`stderr` 输出进展），附 `.agents/skills/ctflow/SKILL.md` 代理技能 |
