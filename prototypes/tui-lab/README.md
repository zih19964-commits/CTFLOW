# CTflow · TUI 交互实验室

五套可玩的浏览器原型，用同一套模拟工作流比较信息布局与操作体验。整体采用黑白终端底色与暖杏色强调。

### 打开试玩

直接双击本目录的 `index.html`，即可离线试玩，无需安装前端依赖。推荐先用 1280×800 或 1024×768 窗口体验，再缩窄窗口比较布局。

也可以在 `E:\CTflow` 的 PowerShell 中启动本地静态服务：

```powershell
.\.venv\Scripts\python.exe -m http.server 8741 --bind 127.0.0.1 --directory prototypes/tui-lab
```

浏览器打开 [http://127.0.0.1:8741/](http://127.0.0.1:8741/)，结束时在终端按 `Ctrl+C`。复制功能受浏览器剪贴板权限限制；直接打开文件时若复制不可用，可改用本地服务或导出 Markdown。

### 五版差别

| 版本 | 布局重心 | 重点试玩 |
| --- | --- | --- |
| 留白 / MONO | 中央对话，流程按需展开，输入区位于底部 | 从自然语言起步，观察方案如何进入对话 |
| 并行 / RAIL | 左侧工具栏，中部对话，右侧执行路线与节点详情 | 边讨论边追踪并行节点与交接 |
| 编排 / CANVAS | DAG 画布居中，右侧检查器，底部命令区 | 检查依赖，添加节点，查看直接上游上下文 |
| 脉冲 / PULSE | 并行时间线、指标与活动日志，右侧节点监视 | 观察并发、故障定位、暂停与重试 |
| 成稿 / STUDIO | 左侧对话约 42%，右侧作品约 58%，顶部流程 | 阅读成稿，切换预览与 Markdown，追溯依据 |

点击顶部标签切换版本。每版独立保存试玩状态；比较时可给五版输入同一目标并选择同一场景。

### 一轮试玩

先选择“审阅方案”“研究问题”或“发布计划”示例，也可以输入自己的目标。Plan 模式先生成方案，Build 模式提交目标后直接运行；`Shift+Tab` 切换模式。输入 `/` 打开命令选单，`↑↓` 选择、`Tab` 补全、`Enter` 执行，`Shift+Enter` 换行。

| 输入 | 行为 |
| --- | --- |
| `/plan 描述目标` | 创建可检查的方案草稿；单独输入 `/plan` 进入目标输入 |
| `/add con after A,B` | 在草稿中加入风险审查节点，依赖 A、B；运行前使用 |
| `/run` | 运行当前方案 |
| `/pause` | 暂停并保留当前进度 |
| `/resume` | 从暂停处继续 |
| `/approve` | 批准人工检查点，继续生成成稿 |
| `/retry` | 重试失败及受阻节点，复用成功结果 |
| `/artifact` | 打开产物，切换预览与 Markdown、复制内容 |
| `/export` | 将已有结果下载为 Markdown 文件 |
| `/new` | 开始当前版本的新会话，保留运行历史与场景设置 |

运行中点击节点，查看“结果 / 上下文 / 活动”；用 `/help` 查看完整命令与快捷键。开始新会话前，进行中的流程需先用 `/stop` 结束。

### 场景与保存

顶部场景入口或 `/scenario` 提供三条体验路径：正常执行会按依赖完成工作流；故障演练让风险节点模拟超时，用 `/retry` 恢复；人工检查会在最终汇总前等待，用 `/approve` 批准继续。建议每版都走一遍“运行 → 检查节点 → 暂停与继续 → 查看产物”，再比较故障与人工检查。

流程推进、输出、证据引用、Token、耗时及模型选择均为浏览器本地模拟，方案来自内置模板；实际模型、工具与 CTflow 后端未接入。页面展示的目标和内容用于体验交互。

页面需要允许使用 `localStorage`，以保存五版状态和各自运行历史。刷新后，原先正在运行的流程恢复为暂停，可用 `/resume` 继续。文件直开与 HTTP 地址的存储彼此独立，不同浏览器也各自保存；清除站点存储会清除试玩记录。

### 设计参考

交互参考 [Grok Build：模式与命令](https://docs.x.ai/build/modes-and-commands)及[键盘快捷键](https://docs.x.ai/build/keyboard-shortcuts)，色彩参考 [OpenCode：主题](https://opencode.ai/docs/themes/)。本原型的可用命令与快捷键以页面 `/help` 为准。

在浏览器中实际完成五版操作，验证命令筛选与补全、`@` 选择、模式切换、Worker 编辑、添加节点、结果与上下文、正常运行、故障恢复、人工检查、运行历史、Markdown 预览、复制与下载。在 1280×800、1024×768 和 390×844 尺寸检查布局。界面截图保存在项目 `artifacts/tui-lab/`。
